### 00～10分钟：准备与预测

- [ ] 容量改为8，列出序号0～23对应的下标；先预测序号0、8、16是否会使用同一槽位对象。

### 10～30分钟：定向阅读

- [ ] 阅读槽位访问方式，写出生产者何时可再次改写该槽位。今天所有观察都在明确完成同步后进行。

### 30～50分钟：最小实验

- [ ] 发布第一轮8条，消费者保存对象引用和独立数据副本两份观察材料；等本轮处理完成后再进行下一轮。

### 50～75分钟：扩展实现

- [ ] 继续发布到100条，完成后查看早期保存的引用与副本。记录同一下标在不同序号下的对象身份和字段内容。

### 75～105分钟：边界与对照

- [ ] 为事件增加一个可选备注，交替发布有值和无值的消息。先观察漏清理时旧值遗留，再补全每次字段赋值并核对。

### 105～120分钟：验收与复盘

- [ ] 画“申请→填充→发布→消费→释放→复用”的生命周期，标明哪一段可以拥有可变引用，异步外送时应保留什么。

## 验证场景与预期

| 场景 | 输入或条件 | 通过标准或应观察的现象 |
| --- | --- | --- |
| 槽位映射 | 容量8，序号0/8/16 | 下标均为0，对象可复用 |
