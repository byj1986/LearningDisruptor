## 120分钟执行顺序

每段完成后再进入下一段；记录预测与实际的差异，数值预期不是已经测得的结果。

### 00～10分钟：准备与预测

- [ ] 设1000条、编号0～999、金额100分；业务规则为编号能被10整除则无效，有效订单费用10分。先算应有900条有效、100条无效。

### 10～30分钟：定向阅读

- [ ] 阅读前置阶段与下游之间的依赖；画A校验→B费用→C汇总，列明每个字段由谁写、由谁读。

### 30～50分钟：最小实验

- [ ] 手写单线程参考计算，保存有效数、无效数、有效金额和费用四项结果。再实现A写有效标志。

### 50～75分钟：扩展实现

- [ ] 实现B仅为有效订单设置费用，无效订单也明确清理字段；C只读结果并累计。为各阶段增加少量编号顺序观察。

### 75～105分钟：边界与对照

- [ ] 先用20条核对逐条结果，再用1000条移除日志；在不同运行中减慢A或B，确认下游依赖仍成立。

### 105～120分钟：验收与复盘

- [ ] 与参考结果对账，解释为何“跳过某条业务计算”仍需处理该序号并推进阶段。记录最后阶段的完成条件。

## 验证场景与预期

| 场景 | 输入或条件 | 通过标准或应观察的现象 |
| --- | --- | --- |
| 小样本 | 0～19 | 有效18、无效2，费用180分 |
| 完整样本 | 0～999 | 有效900、无效100，有效金额90000分，费用9000分 |
| 慢前置阶段 | 减慢A或B | C结果不变，不读取未完成阶段结果 |

## 卡住时先检查

- 不要在事件仍无效时保留旧费用。
- 等待完成要以C为准，A处理完不代表汇总完成。
