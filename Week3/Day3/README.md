## 120分钟执行顺序

每段完成后再进入下一段；记录预测与实际的差异，数值预期不是已经测得的结果。

### 00～10分钟：准备与预测

- [ ] 复用1000条输入与第12天规则。改画生产者→A校验/B独立费用→C汇总；先解释B为何能仅依赖原始输入独立计算。

### 10～30分钟：定向阅读

- [ ] 阅读多个前置处理器汇合的配置。列出A独占的有效标志、B独占的费用与完成标记，C负责按有效性选取结果。

### 30～50分钟：最小实验

- [ ] 先实现两个分支，C同时依赖A和B；每次填槽位时清理分支输出，避免旧标志伪装为已完成。

### 50～75分钟：扩展实现

- [ ] 用20条观察A/B完成次序，C记录自己看到的两分支标记与结果；只要求对应序号的两个分支都已完成。

### 75～105分钟：边界与对照

- [ ] 分别暂停A和暂停B，再恢复，主控设置超时且finally释放信号。观察另一个分支能否领先、C何时恢复。

### 105～120分钟：验收与复盘

- [ ] 核对1000条有效数与费用仍与参考一致。比较串行和菱形的线程数量、协调点和完成条件。

## 验证场景与预期

| 场景 | 输入或条件 | 通过标准或应观察的现象 |
| --- | --- | --- |
| 正常汇合 | 1000条 | 有效900、无效100，汇总费用9000分 |
| A暂停 | 只释放B | C不得消费缺少A结果的对应事件 |
| B暂停 | 只释放A | C不得提前汇总未产生的费用 |

## 卡住时先检查

- 两个阶段不要共同写一个Dictionary或List而无额外同步。
- 不要仅以费用为0判断B未完成，真实业务可能有零费用；实验使用独立完成标记。
