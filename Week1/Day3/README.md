## 验证场景与预期

| 场景 | 输入或条件 | 通过标准或应观察的现象 |
| --- | --- | --- |
| 单次数据发布 | 100轮，每轮独立状态 | 观察到就绪后两个字段均正确 |
| 等待超时 | 故意不发通知，超时500ms | 报告超时并结束，不把默认数据当成功 |
| CAS计数 | 4×100000 | 最终400000；重试次数不作固定要求 |

## 卡住时先检查

- 不要在一轮尚未结束时复用并重置就绪标志。
- CAS重试计数本身也属于共享状态；可按任务分别累计后汇总，避免再引入数据竞争。
