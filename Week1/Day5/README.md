## 120分钟执行顺序

每段完成后再进入下一段；记录预测与实际的差异，数值预期不是已经测得的结果。

### 00～10分钟：准备与预测

- [ ] 切换环形缓冲区项目，纸上画容量8、槽位0～7。约定读写逻辑序号从0递增，记录如何判断空与满。

### 10～30分钟：定向阅读

- [ ] 阅读并推导：逻辑序号不断增加，下标反复回绕。用0、7、8、15、16五个序号计算下标；先用取模表达。

### 30～50分钟：最小实验

- [ ] 手写TryWrite/TryRead：写满前8条成功，第9次失败；读空后下一次读取失败。失败操作不应破坏现有内容和进度。

### 50～75分钟：扩展实现

- [ ] 交替填满、读取、再填满，处理至少100条。每次读取都与参考队列或预期编号比较，覆盖空、满和跨圈三种边界。

### 75～105分钟：边界与对照

- [ ] 回到Channel基础项目增加Stopwatch；分别记录生产结束时刻与最终消费结束时刻，给消费者少量延迟，观察两个时刻的差别。

### 105～120分钟：验收与复盘

- [ ] 保存环形容器边界表及计时对照。画出回绕后槽位被复用的一例，并说明这个实现尚不具有并发安全保证。
